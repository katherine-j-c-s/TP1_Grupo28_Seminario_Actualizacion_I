# Book Manager — Sprint 1

## Objetivo

Aplicar programación orientada a objetos y persistencia en archivos para gestionar el inventario de una librería, cotizar los libros según el dólar y comparar esos costos con los precios públicos de [Cúspide](https://cuspide.com/).

## Introducción y contexto

Sprint 1. El sistema es una aplicación de consola. El código está en `book_manager/`, con entidades encapsuladas, CRUD en CSV, servicios de negocio y menú de consola. El detalle del sprint, los reportes y la forma de ejecutarlo están en [book_manager/README.md](book_manager/README.md).
