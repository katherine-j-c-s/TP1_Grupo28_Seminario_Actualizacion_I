# Book Manager — Sprint 2

## Objetivo
Migrar la capa de persistencia a una base de datos relacional utilizando **SQLAlchemy**, integrando la consulta de cotizaciones del dólar en tiempo real vía API externa y ampliando la consola con reportes bimonetarios.

## Introducción y Contexto
En este sprint se implementa un modelo relacional con SQLite/SQLAlchemy, migración automatizada de los CSV del Sprint 1 a scripts SQL y transacciones seguras.
